737.gmsh_r

Gmsh is an open source 3D finite element mesh generator with a built-in CAD engine and post-processor. Its design goal is to provide a fast, light, and user-friendly meshing tool with parametric input and flexible visualization capabilities. Gmsh is built around four modules (geometry, mesh, solver, and post-processing), which can be controlled with a graphical user interface, from the command line, using text files written in Gmsh's own scripting language (.geo files). SPEC CPU specifically uses standalone .geo files, and only tests the meshing module as it is the most computationally intensive of the four modules.

Official description is available at https://www.spec.org/cpu2026/Docs/benchmarks/737.gmsh_r/737.gmsh_r.html.

Please note that the -Ofast compilation also additionally used option -fno-fast-math. (In future measurements, we will try to enable at least -fno-math-errno and -fno-trapping-math which are on in LLVM-based compilers also at lower optimization levels.)

DISCLAIMER: All the SPEC results are "non-reportable". The measurements were taken in order to compare different compilers and compiler options, not different hardware, please do not attempt to make any comparisons of the different machines used. Moreover, we have broken various SPEC benchmarking rules, we have even patched some benchmark sources to be able to compile them with -fstrict-aliasing, build with -fno-common, and so forth. And the data may be just wrong, the scripts generating all the fancy graphs and tables have been known to contain bugs in the past. On the other hand, this is the data that we use to evaluate where GCC stands and we believe that overall this comparison of compilers is a useful one.
