15th October 2026 - Normalized report

782.lbm_r

This program implements the so-called "Lattice Boltzmann Method" (LBM) to simulate incompressible fluids in 3D as described in [1]. It is the computationally most important part of a larger code which is used in the field of material science to simulate the behavior of fluids with free surfaces, in particular the formation and movement of gas bubbles in metal foams. For benchmarking purposes and easy optimization for different architectures, the code makes extensive use of macros which hide the details of the data access. A visualization of the results of the submitted code can be seen below (flow through a porous medium, grid size 200x200x130, 1200 time steps).

Official description is available at https://www.spec.org/cpu2026/Docs/benchmarks/782.lbm_r/782.lbm_r.html.

DISCLAIMER: All the SPEC results are "non-reportable". The measurements were taken in order to compare different compilers and compiler options, not different hardware, please do not attempt to make any comparisons of the different machines used. Moreover, we have broken various SPEC benchmarking rules, we have even patched some benchmark sources to be able to compile them with -fstrict-aliasing, build with -fno-common, and so forth. And the data may be just wrong, the scripts generating all the fancy graphs and tables have been known to contain bugs in the past. On the other hand, this is the data that we use to evaluate where GCC stands and we believe that overall this comparison of compilers is a useful one.
